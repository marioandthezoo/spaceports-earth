LINK → MP4

MDL LC-4400
FORMAT CONVERTER
Rewrites any https link into a custom address that ends in .mp4. Paste one or many, set your naming pattern, copy the result.
one https link per line
naming pattern
Tokens: {id} video ID  {slug} last path segment  {host} source site  {path} full path  {url} original link, encoded  {ts} timestamp. If the pattern doesn't end in .mp4, it gets appended.
OUTPUT
Note: this converts the address itself. For the new link to actually play or download a video, the pattern needs to point at a server, worker, or redirect that serves the file — a real .mp4 URL will then embed directly in places like Discord.
